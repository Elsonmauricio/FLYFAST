# 🚀 FLYFAST Backend API

Backend completo para o sistema de envios FLYFAST, conectando Angola e Portugal.

## ✨ Funcionalidades Implementadas

### 🔐 Autenticação & Autorização
- JWT-based authentication
- Firebase Auth integration
- Role-based access control (User/Staff/Admin)
- Password recovery system

### 📦 Sistema de Envios
- Gerenciamento completo de envios
- Rastreamento em tempo real
- Histórico de localizações
- Cálculo automático de custos
- Sistema de seguros

### 🛍️ Loja Online
- Catálogo de produtos
- Carrinho de compras
- Checkout com múltiplos métodos de pagamento
- Gestão de encomendas
- Sistema de descontos

### 👔 Personal Shopper
- Gestão de pedidos personalizados
- Sistema de atribuição a staff
- Comunicação cliente-staff
- Cálculo automático de taxas
- Rastreamento de compras

### 📢 Sistema de Notificações
- Email (Nodemailer)
- WhatsApp Business API
- SMS (Twilio)
- Push notifications (Firebase)
- Preferências configuráveis por usuário

### 💳 Sistema de Pagamentos
- Stripe integration (cartões, MB Way)
- PayPal integration
- Gestão de transações
- Webhooks para confirmações
- Suporte multi-moeda (AOA, EUR)
