# 🚀 FLYFAST Website

Website completo para a empresa de envios FLYFAST, conectando Luanda e Lisboa.

## ✨ Funcionalidades

✅ Página inicial com apresentação da marca  
✅ Sistema de rastreamento de envios em tempo real  
✅ Loja online com merchandising e materiais de envio  
✅ Personal Shopper (compra assistida)  
✅ Agenda de rotas e reservas de envio  
✅ Área do cliente com histórico completo  
✅ Sistema de contacto e suporte  
✅ Design responsivo e moderno  
✅ Identidade visual consistente (amarelo/azul)  

## 🛠️ Tecnologias

- **Frontend:** React 18
- **Estilização:** Tailwind CSS
- **Roteamento:** React Router DOM 6
- **Ícones:** React Icons
- **HTTP Client:** Axios

## 📦 Instalação

```bash
# Clonar o repositório
git clone [url-do-repositorio]

# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm start

# Build para produção
npm run build
